Any mail app that speaks IMAP can use Rootiest Mail. Before you start, make an app password for the app. You'll paste it in wherever the app asks for a password.

Step-by-step guides

  • Thunderbird on Windows, Mac or Linux
  • Thunderbird for Android
  • Apple Mail on iPhone, iPad and Mac
  • Outlook

For any other app, the settings below are all you need.

Automatic setup

Thunderbird and Outlook can look up the settings on their own. Type your address and app password, and they fill in the rest. When they do, they'll show the provider as rootiest.org. That's normal.

Other apps try to guess the server names and usually guess wrong. If an app says it can't find the settings or can't connect, switch to manual setup and use the table below.

Note that the server is mx.rootiest.dev, with .dev, even though your address ends in .org. Names like mail.rootiest.org or imap.rootiest.org don't work.

Things that trip people up

  • Use SSL/TLS, not STARTTLS. Some apps suggest port 587 with STARTTLS for outgoing mail. That port isn't open here, so pick SSL/TLS on port 465 instead.
  • The outgoing server needs a login too. Some apps mark the outgoing username and password as optional. Fill them in anyway, or sending fails.
  • IMAP, not POP. POP isn't offered. IMAP keeps your mail on the server, so every device sees the same thing.
  • Messages can be up to 100 MB. Most other providers refuse anything much over 25 MB though, so share big files another way.

They use the same username (your full address) and an app password. If an app only asks for a server name, try mx.rootiest.dev. See Calendars and contacts for which apps to use.

About JMAP

JMAP is a newer way for apps to talk to a mail server. It's faster than IMAP and covers mail, calendars and contacts in one go. Only a handful of apps support it so far, so if you don't know whether you need it, you don't. If your app does support it, give it your address and an app password and it should find the server from the JMAP address above.
